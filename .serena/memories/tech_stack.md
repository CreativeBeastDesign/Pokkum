# Technology Stack & Dependencies

- **Language**: Go 1.26+ (go directive 1.26.6 in `go.mod`)
- **Application Framework**: SvelteKit 2.31+ (`@sveltejs/kit`)
- **Runtime Dimension (`--runtime=bun|node`, default `bun`, added 2026-08-19)**: orthogonal to strategy, restricted to `--strategy=layered`. `node` targets a dedicated `distroless-node` preset (`gcr.io/distroless/nodejs24-debian12:nonroot`, its own `pokkum.lock` slot so it can't collide with a bun-targeted custom base) and ships no Bun layer at all — the entrypoint execs `/nodejs/bin/node` directly. Node's integrity comes from the base image's existing keyless-verification + lockfile-digest-pinning machinery rather than a Pokkum-side download-and-verify path (a deliberate tradeoff: Node's multi-person rotating release-key model over `SHASUMS256.txt` would be materially more surface to replicate at Bun's integrity strength). Joins the composite cache hash, `pokkum.lock` keying, CVE lookup, and SLSA `externalParameters.runtime`; non-default runtimes get a `dev.pokkum.runtime` label. Rejected combinations (positive switch, not negative): `--telemetry`, `--stub-launcher`, `--bun-binary`, explicit `--bun-version`/`--bun-variant`, and the bun-only presets. Open gaps: no node+telemetry, no Node-core CVE lookup (distroless ships Node outside `dpkg`), no `dev`/`resolve`/`apply`/standalone-`scan` runtime awareness, no boot smoke test (proven once manually against a real Docker boot). See `Roadmap.md` 1.3 and `ARCHITECTURE.md` §8.
- **Runtime Compiler & Resolver**: Bun ≥ 1.2.0 (`internal/adapters/bunruntime` resolver, `--bun-binary`, `--bun-variant=standard|baseline`, `--stub-launcher` for compiled entrypoint launcher stubs). Release integrity (fixed 2026-08-17): a static `pinnedReleaseChecksums` map covers 3 known `1.2.2` entries (fast, no network); any other `--bun-version` is verified against Bun's own GPG-signed `SHASUMS256.txt.asc` via `github.com/ProtonMail/go-crypto/openpgp` (`clearsign.Decode` + `openpgp.CheckDetachedSignature`/`Block.VerifySignature`) against an embedded release-signing key (`Robobun <robobun@oven.sh>`, fingerprint confirmed against a real signature before pinning). `Resolver.ReleaseKeyArmored` allows tests to inject a throwaway keypair. Fails closed (`core.ErrBunSignatureVerificationFailed`, `core.ErrBunChecksumMismatch`) on any fetch/signature/checksum failure — no unverified download is ever installed.
- **Packaging Strategy & Adapter**: `--strategy=layered` (default, arch-independent layout via `@sveltejs/adapter-node`) / `--strategy=exe` (deprecated 2-layer single executable) / `--strategy=static` (via `@sveltejs/adapter-static`, served by `pokkum-static`)
- **Zero-Config Auto-Injection**: `sveltekitutils.TransformViteConfig` + `bunexec.Compiler.Prepare` via `.pokkum/vite.config.ts` wrapper and `bunx vite build --config .pokkum/vite.config.ts` (Option B), with `checkEffectiveAdapter` fail-fast backstop (Option C) when `--no-inject` is set.
- **Embedded Static File Server**: `pokkum-static` (`supervisor/cmd/pokkum-static`) — a statically-linked PID-1 Go HTTP file server embedded zstd-compressed by `internal/adapters/staticserver` (`ports.StaticServerProvider`, built by `make static-server`), serving the `--strategy=static` `client` + `prerendered` trees with Range/ETag/Content-Encoding support. Base image for that path: `cgr.dev/chainguard/static` (libc-free), defaulted by the `--static` flag when no `--base`/`--hardened` is given.
- **`sync.Pool` Buffer Recycling**: `poolutils` (`internal/adapters/poolutils/poolutils.go`) recycles 64KB I/O copy buffers and bounded `bytes.Buffer` instances across tar archiving, layer streaming, hashing, and pre-compression.
- **Composite Remote OCI Input Caching**: `remotecacheutils` (`internal/adapters/remotecacheutils/remotecacheutils.go`) calculates composite input digests (including `StubLauncher` sensitivity) to achieve sub-100ms build avoidance against remote registries. Escape hatch: `--no-cache`.
- **Static Asset Pre-Compression**: `precompressutils` (`internal/adapters/precompressutils/precompressutils.go`) pre-compresses `/app/client`/`/app/prerendered` assets using pure-Go Brotli (`github.com/andybalholm/brotli`), Zstandard (`github.com/klauspost/compress/zstd`), and Gzip (`github.com/klauspost/compress/gzip`, pinned since 2026-08-17, not stdlib `compress/gzip`). Format selection per `PrecompressOptions{Gzip, Brotli, Zstd bool}`: layered requests gzip+brotli only, static requests all three. Escape hatch: `--no-precompress`.
- **ELF Native Addon Stripping**: `striputils` (`internal/adapters/striputils/striputils.go`) strips unneeded debug symbols from native `.node` modules and `.so` libraries in `/app/native` and `/app/vendor`. Escape hatch: `--no-strip`.
- **Layer Assembly & Compression**: Single-pass streaming pipeline (`buildSinglePassLayer`) computing uncompressed `DiffID` and compressed `Digest` simultaneously; `--compression=gzip|zstd` (default: `gzip`, `application/vnd.oci.image.layer.v1.tar+zstd` when `zstd`). The gzip codepath (`packager/layer.go`) is pinned to `github.com/klauspost/compress/gzip` (not stdlib `compress/gzip`, since 2026-08-17), so compressed layer bytes are stable across Go toolchain versions — closes the old L1-vs-L2 gzip framing skew caveat.
- **Layer Caching**: `layercacheutils` (`internal/adapters/layercacheutils/layercacheutils.go`) caches immutable compressed layer tarballs (`bun`, `supervisor`, `stubs`) in `~/.cache/pokkum/layers/` and `~/.cache/pokkum/bun/stubs/`.
- **Vendor Layer Optimization**: `pruneutils` (`internal/adapters/pruneutils/pruneutils.go`) automatically strips non-runtime files (`*.d.ts`, `*.map`, `tsconfig.json`, `README*`, tests) from `/app/vendor`, saving 15–35MB per image. Escape hatches: `--no-prune`, `--keep-vendor`.
- **Native Addon Closure & Splitting**: `ClosuredNativeAdapter` (`internal/adapters/nativeinspect/closured.go`), ELF `.node` addon inspection, `/app/native` layer, and vendor chunking (`/app/vendor`).
- **Security & Hardening**: Container `securityContext` defaults inject `runAsNonRoot: true`, `allowPrivilegeEscalation: false`, `readOnlyRootFilesystem: true`, `capabilities.drop: [ALL]`, `seccompProfile: RuntimeDefault`. Optional compiled stub launcher (`--stub-launcher`) and supervisor pre-exec startup attestation (`POKKUM_ATTESTATION_DIGEST`).
- **OCI Container Engine**: `github.com/google/go-containerregistry` (no Docker daemon required for builds)
- **Local Dev Engine**: `pokkum dev` (`cmd/pokkum/dev.go`) for local Docker daemon load, `--debug` interactive shell, and file watching.
- **Base Images**: Distroless (`gcr.io/distroless/cc-debian12:nonroot`) or Chainguard (`ghcr.io/chainguard-images/glibc-dynamic:latest`)
- **Observability**: Native OpenTelemetry Node SDK (`@opentelemetry/sdk-node`, `@opentelemetry/api`)
- **Supply Chain Security**: Native zero-dependency targeted scanner & SBOM generator (`scannerutils`, `sbom` attached via OCI 1.1 referrers by default `--sbom-attach=referrer` or tag `--sbom-attach=tag`), Cosign (ECDSA/Ed25519 image signing), SLSA v1.0 (in-toto provenance with DSSE envelopes), Keyless Sigstore (Fulcio+Rekor). `sbom` catalogs npm packages plus (fixed 2026-08-17) the embedded Bun runtime as its own component (`pkg:generic/bun@<version>`, hash when known) via `SBOMRequest.BunVersion`/`BunSHA256` — `internal/core/pipeline.go`'s `Build` pre-resolves Bun once (ahead of the per-platform fan-out) and threads the same value into both the SBOM and the SLSA `Toolchain.BunVersion`/`BunBinaryHash` fields (previously: `BunBinaryHash` was never actually populated in a real build despite `slsa/generator.go` supporting it since inception; `BunVersion` incorrectly used the host compiler's bun instead of the resolved embedded runtime).
